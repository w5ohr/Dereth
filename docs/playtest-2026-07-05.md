## FIXED — 2026-07-05

### Graphics / world geometry
- **✅ G1 — Lifestone read as an oversized "insectoid" crystal.** The crystal geometry was fine
  (native 3.6m upright spire); the "wider than tall" reading was the group bbox contaminated by the
  flat clearing disc (r 4.6 → 9.2 diameter). Fix (`buildLifestone`): normalise the crystal to a
  ~2.6m landmark spire seated on `groundY`, and shrink the clearing disc r 4.6 → 3.0. Verified now
  2.15w × 2.6h × 2.02d, base on ground.
- **✅ G2 — Overworld monsters rendered buried ~90u underground** (19 of 32 far mobs). A mob's mesh-y
  was only set to `groundY` while simulated (`SIM_RADIUS`=95); un-simulated ones kept spawn-y=0.
  Masked at old ⅓ scale, exposed at 1:1. Fix: `spawnMonster` seats mobs at `groundY(x,z)`, plus a
  sim-skip safety net planting far idle mobs each tick. Verified 0 buried (was 19).
- **✅ G3 — PK altars buried ~28u underground.** `addPKAltar` used `y=0` instead of `groundY`. Fixed;
  both Holtburg altars now seat on the terrain.
- **✅ G4 — Untextured glaring-white building panel at Shoushi.** Some AC building surfaces carry a
  near-white "unset texture" placeholder that rendered as a blank white panel under PBR sun. Fix
  (`tbBuildMesh`): tone any untextured near-white surface (all channels > 190) to muted stone
  `0x9c9078`, roughness 0.94. Verified 0 glaring-white surfaces at Shoushi.

### Economy / gameplay
- **✅ Economy — infinite-money loop at trade-note / low-value vendors** (🔴 HIGH). Buy Trade Note
  (100) for 2p, sell back for 3p → +1p/cycle forever (the 2p buy-clamp floor undercut the generic
  sell value). Fix: trade notes sell at face−1, and every vendor-bought item is stamped with its buy
  price (`bp`) which hard-caps its resale at `bp−1` — closes the whole exploit class (also caught a
  Ginseng/comp variant). Verified live (net negative over cycles). Shipped on `fix-money-exploit`.
- **✅ Death — dead player could act during the 1.4s death fade.** `interact()` had no `player.alive`
  guard, so pressing E on the death spot instantly recovered your own corpse, erasing the corpse-run
  penalty. Fix: gate `interact()` on `player.alive`. Shipped on `fix-playtest-findings`.
- **✅ Magic — 881 vendor spell scrolls were unlearnable curios** (🔴 HIGH). Retail scroll items in
  ACE vendor stock fell through `acItemRow` to 📦 trophy curios — none scribeable, and since acStock
  *replaces* generic stock, ACE-stocked towns sold no learnable scrolls at all. Fix: (a) `acItemRow`
  maps scroll names to real scribeable scrolls when the spell exists in `SPELLBOOK`; (b) every ACE
  archmage/scrivener also carries the standard 30-scroll shelf. Verified end-to-end: buy → scribe →
  train school → cast.
- **✅ Inventory — quest items were sellable** (🟡). The sell list offered quest items (Calling
  Stone, Letter From Home) — selling one could strand its quest. Fix: skip `stat==="quest"` in the
  sell list (as scrolls already are). Shipped on `fix-playtest-findings`.

### Code robustness
- **✅ P3-1 — skill helpers crashed / polluted the save on an invalid skill key.** `skillState()`
  persisted a junk `{t:0,xp:0}` for any key, and `skillBase`/`skillValue`/`skillEff`/`trainSkill`/
  `specSkill` dereferenced `SKILL_BY_KEY[key]` (`.d`/`.tc`/`.sc`/`.base0`/`.fam`) unguarded — an
  unknown key (stale save, renamed skill, bad caller) threw `Cannot read properties of undefined`.
  Not reachable via the UI (keys always come from `SKILLS_DEF`), so defense-in-depth. Fix: guard all
  six helpers — unknown key now returns safe defaults (0 / 1× / false) with no throw and no save
  pollution; valid keys unaffected (verified regression-clean). Shipped in PR #76.

### Verified authentic — NOT a bug (no change)
- **GP1 — Health = Endurance/2.** A high-Endurance char shows mhp = Endurance/2 (e.g. End 100 → 50).
  This is the real retail AC formula (Health = End/2, Stamina = End, Mana = Self) per `derive()`.
  Changing it would break the authenticity mandate. Players raise HP the AC way (the Health vital,
  +1 mhp/rank, verified 50→53; and Endurance climbs with XP). Working as intended.

## Candidates investigated → NOT bugs (harness test-input artifacts)

From the systems pass — each traced in source and confirmed as a test-setup mistake, not a game bug:
- **Missile ammo "not consumed" / 0-count fires** — read the wrong ammo stack (crossbow quarrels vs
  bow arrows) and forced an impossible `count:0` stack; `fireArrow` does consume ammo and
  `takeFromInv` removes a stack at count 0.
- **Attr buff "no-op"** — the Creature school was never trained (out of *skill credits*, which come
  from leveling, not granted XP), so `canCast` correctly rejected the cast. Confirmed working when
  force-trained.
- **Tinker "no-op" on a bow** — `MAT_APPLY['Steel']` resolves to **armor** (armor loop wins), so a
  Steel bag on a weapon is a no-op by design; weapon tinks need a weapon-class material (Titanium).
- **"Stuck" cast** — headless frame sparsity + `dt` clamp (0.05/frame) means 2.5s wall ≪ 0.4s cast
  time in a heavy scene; the loop is alive, the cast just hadn't finished. Test effects via the
  instant `executeSpell` path.

## Test-harness notes (not game bugs)

- **`WrongDocumentError … pointer lock`** — thrown by `cEl.requestPointerLock()` in `startGame()`
  under headless (no user gesture). Harmless; runs inside a click handler in a real browser.
- **Boot is heavy** — `startGame()` → `buildWorld()` builds the ~4M-vertex terrain (GROUND_SEG 2000)
  synchronously (~30s under software WebGL). Real-GPU cost is negligible.
- **Sparse headless frames + `dt` clamp** — `loop()` clamps `dt=min(dt,0.05)`; under SwiftShader with
  a heavy scene, game-time advances far slower than wall-clock, skewing time-based tests (cast bars,
  projectile travel). Verify such effects via instant paths or give generous waits.
- **Adaptive graphics downgrade** — the ~0.5fps headless loop trips the "frame rate dipped below 30
  → step graphics down" system, so some earlier "over-bright/washed-out" observations were captured
  in a downgraded state, not true bugs. Re-verify any *lighting/texture-wash* finding at forced-High
  on real hardware. (Structural/geometry findings — buried-y, scale — are quality-independent.)
- **Out-of-loop `renderComposite()`** with `running=false` corrupts the post-processing render
  targets → black viewport. Harness artifact, recovered by reload; not a game bug.
